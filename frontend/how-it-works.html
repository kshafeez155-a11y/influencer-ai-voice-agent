On this pageBeforeDuringAfterLimits

1. Choose and consent

Creator profiles explain who the AI persona is, what it is useful for, and whether the profile is a demo or an approved creator. Agree to live microphone processing, then allow browser access for this AI conversation.

2. Talk naturally

The live session opens in the profile and identifies itself as AI. Speech is transcribed so the system can form a response, then a synthetic voice speaks it back. You can interrupt and end the call whenever you want.

3. Leave feedback or report a problem

Afterward, use the feedback page for product feedback or report a safety issue. These are separate paths so urgent concerns are not buried in ratings.

What it is not

  • It is not a call with the real person.
  • It is not professional medical, legal, financial, or crisis advice.
  • It does not place an outbound phone call.
  • Current beta calls are intended to last up to five minutes.
