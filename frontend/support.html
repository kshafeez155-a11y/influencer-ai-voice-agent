Help without a maze

What went wrong?

Start with a quick answer. If that does not solve it, send a support request that reaches the operator inbox.

The web call did not start

Allow microphone access when asked. The profile shows “Web calls paused” when a provider is unavailable. Reload once before trying again.

The call ended or went silent

Web connections and real-time voice providers can drop a session. End it and start a new call; beta calls are not billed.

I heard a conversation I did not start

End the session and use the report form. Include the profile and approximate time so it can be investigated.

How do I remove my data?

Use the dedicated data request page. A contact detail is required to verify the request.

Send a support request

Do not include passwords, OTPs, or payment details.
